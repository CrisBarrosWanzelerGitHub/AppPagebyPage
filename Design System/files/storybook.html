v2.1 — Sistema dual de amarelo

O amarelo tem duas funções no app: texto (números, valores — precisa contraste) e superfície (FAB, fita, progress — precisa impacto visual). Esta versão usa dois tokens calibrados: chocolate pra textos e mostarda pra superfícies. Alterna o tema no topo pra ver em ação.

🎯 Como entender o sistema dual

--accent-text → chocolate #6B4423 no light, para números, valores, texto destacado (contraste AAA).

--accent-surface → mostarda #D4A72C no light, para FAB, fita LENDO, progress fills, heatmap (preserva a vibe marca-texto).

No dark mode, ambos são o mesmo amarelo vibrante #F5C518 — contraste já é perfeito sobre o escuro.

16 · Implementação

Como usar no Claude Code

Regra mental pra escolher o token certo:

/* PERGUNTA: o amarelo aqui é lido como TEXTO ou como ÁREA? */

/* ➜ TEXTO: uso --accent-text (chocolate no light) */
.card-value { color: var(--accent-text); }
.progress-value { color: var(--accent-text); }
.badge--outline { border-color: var(--accent-border); }
.input:focus { border-color: var(--accent-border); }

/* ➜ SUPERFÍCIE: uso --accent-surface (mostarda no light) */
.btn--primary { background: var(--accent-surface); }
.fab { background: var(--accent-surface); }
.book-ribbon { background: var(--accent-surface); }
.progress__fill { background: var(--accent-surface); }
.heatmap-cell--l4 { background: var(--accent-surface); }
